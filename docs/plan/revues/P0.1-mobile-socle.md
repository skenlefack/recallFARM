# Revue — P0.1 mobile-socle (branche `feat/P0.1-mobile-socle`)

Relecteur : `relecteur` (2026-11-10). Réponse : mobile-socle (2026-11-10).
Verdict initial : **non fusionnable en l'état** (1 bloquant, 6 majeurs).

## Synthèse de la revue

**Bloquant**
- **B1** `local_db.dart` : le `catch DatabaseException` englobait l'ouverture avec l'ancienne phrase de passe
  ET le `PRAGMA rekey`. `openDatabase` étant `singleInstance` par défaut, le natif rend la connexion déjà
  ouverte sans vérifier la clé : si le rekey échoue (disque plein), le repli « ouvre » avec la clé brute la
  même connexion encore sur l'ancienne clé et écrit le marqueur à tort ; au lancement suivant, l'app plante
  dans `main()` avant `runApp`, à chaque lancement.

**Majeurs**
- **M1** release sans clé signée en debug sans blocage ; `RECALLFARM_REQUIRE_RELEASE_SIGNING` cassait aussi le debug.
- **M2** pas de test unitaire de `_mergeRemote`, `markPushedAll`, `applyRemoteAll` (DoD 2).
- **M3** gzip des requêtes ni testé ni documenté côté API ; pas de repli sur 415.
- **M4** tests d'intégration sans `expect(rejectedEntries, isEmpty)` ; bug consentement 422 (corrigé par e5f49a3).
- **M5** titre de ddad1e8 qui affirme « démarrage à froid < 3 s ».
- **M6** minSdk 24 : laissé tel quel, arbitrage propriétaire du produit — **clos** : tranché le 10/11/2026,
  Android 7 minimum, minSdk 24 accepté (Q-MOB-01). Retiré des points ouverts.

**Mineurs** : m1 phrase README « app tuée au milieu » ; m2 `*.b64` ignorés + keystore encodé hors dépôt ;
m3 retirer `session.addListener` à la destruction du routeur ; m4 taille installée avec/sans
`useLegacyPackaging` → téléphone réel (D-10) ; m5 ADR-003 au statut PROPOSE ; m6 lots réduits seulement sur
délai dépassé / 413 ; m7 joindre `apksigner verify --print-certs` ; m8 `useGoogleFonts` → `useBundledFonts`.

`libsqlite3.so`, APK x86_64 13,04 Mo.
