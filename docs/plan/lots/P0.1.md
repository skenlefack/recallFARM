# Lot P0.1 — Mobile compile et prouve sur appareil

## Objectif
L'application Flutter jamais compilee devient un APK qui s'installe, demarre et passe ses tests.

## Exigences couvertes
- Toutes les exigences mobile existantes (E01-E72)
- RG-PAR-02 (parite des moteurs Dart)

## Hors perimetre
- Nouveaux ecrans ou fonctionnalites
- Modifications des moteurs (sauf corrections pour compiler)

## Agents et vagues

### Vague 1 (parallele)
- **mobile-socle** (chef) :
  1. `flutter create --platforms=android,ios --org app.recallfarm .` sans ecraser lib/
  2. AndroidManifest : INTERNET, POST_NOTIFICATIONS, SCHEDULE_EXACT_ALARM
  3. minSdk 23, desugaring, cleartext limite a 10.0.2.2 en debug
  4. flutter pub get, corriger TOUTES les erreurs de flutter analyze
  5. Embarquer les polices (pas de telechargement a l'execution)
  6. flutter test : 100 % vert sans toucher aux vecteurs

- **mobile-ecrans** :
  1. Chaque ecran s'affiche sans exception sur emulateur 360x640 et 412x915
  2. Goldens par ecran
  3. Corriger les debordements

### Vague 2
- **qa-automatisation** : integration_test du parcours pilote contre la pile docker
- **ux-fidelite** : captures des 6 ecrans maquettes vs docs/design/Mobile*.dc.html

## Criteres d'acceptation
- [ ] APK release signe < 25 Mo
- [ ] Demarrage a froid < 3 s sur emulateur 2 Go
- [ ] flutter analyze : 0 avertissement
- [ ] flutter test : 100 % vert
- [ ] Parcours pilote integration_test vert 3 fois de suite
- [ ] Aucune perte de donnees apres 50 cycles mode avion
- [ ] Captures conformes aux maquettes

## Decisions requises
- D-02 : Confirmer sqflite_sqlcipher (ADR a ecrire)
- D-09 : Polices embarquees (recommande : oui)

## Risques
- Incompatibilites de dependances Flutter non decouvertes
- sqflite_sqlcipher peut poser probleme sur certains appareils
- Les tests widgets existants peuvent echouer sur des details de rendu
