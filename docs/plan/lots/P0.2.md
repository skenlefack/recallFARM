# Lot P0.2 — Livraison conteneurisee reelle

## Objectif
La pile se construit, se deploie et se surveille, sur une recette publique.

## Agents
- **devops-sre** (chef), puis **securite-conformite**

## Taches
1. Construire les images api et web, scanner (Trivy : 0 critique), corriger Dockerfiles
2. `make up` depuis un clone propre : tous services healthy en < 3 min ; make seed ; parcours web OK
3. Environnement de recette sur VM (2 vCPU, 4 Go) : Caddy + Let's Encrypt, pare-feu 22/80/443
4. Observabilite : journaux JSON, Prometheus, Grafana, Loki, alertes
5. Sauvegardes : profil backup, copie hors machine, restauration testee (RB-05, RB-06)

## Criteres d'acceptation
- [ ] Images construites et scannees (0 critique Trivy)
- [ ] make up depuis clone propre : healthy en < 3 min
- [ ] URL de recette en HTTPS (note A SSL Labs)
- [ ] Restauration de sauvegarde prouvee
- [ ] Runbook a jour
- [ ] Alertes configurees (API down, file > 1000, SMS echec > 5 %)
