# Lot P0.4 — Banc de tests de non-regression

## Objectif
Aucune regression ne peut plus entrer sur main.

## Agents
- **qa-automatisation** et **moteurs-parametrage** ; puis **relecteur**

## Taches
1. Lanceur de parite (/parite) : vecteurs TS et Dart compares octet par octet ; job CI bloquant
2. Tests de proprietes (fast-check / glados) : 10 000 expressions et contextes, compare TS/Dart
3. e2e web Playwright sur la pile docker (connexion, tableau de bord, studio 4 yeux, abonnement)
4. Tests de contrat : chaque reponse e2e validee contre openapi.json
5. Charge k6 : 300 utilisateurs simultanees, synchro + ordonnanceur 50 000 rappels/jour ; p95 < 300 ms

## Criteres d'acceptation
- [ ] CI < 15 min
- [ ] Tous les jobs CI bloquants
- [ ] Parite TS/Dart : 0 ecart
- [ ] Tests de proprietes : 10 000 cas sans divergence
- [ ] e2e Playwright : parcours complet vert
- [ ] Charge k6 : p95 < 300 ms, 0 erreur
- [ ] Rapport de charge archive
