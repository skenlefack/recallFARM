# Lot P0.3 — Solder la dette du MVP

## Objectif
Corriger les 5 dettes techniques identifiees qui fragilisent le pilote.

## Agents (parallele), puis relecteur

### integrations
- Regroupement des rappels du meme jour en un seul SMS par destinataire (RG-NOT-02)
- Limitation de debit et verrous sur Redis (plus de stockage memoire)
- File d'envoi persistante avec reprise et file morte

### moteurs-parametrage
- Publication d'un protocole → recalcul des rappels non realises (tache de fond idempotente)
- Rapport d'impact (nombre de sujets) visible dans le diff du studio
- Deploiement progressif effectif (pourcentage d'exploitations, EF-PAR-09)

### backend-elevage
- Compte provisoire hors ligne reellement rattache a la verification OTP (provisional_user_id, fusion)
- Suppression de compte avec OTP, retractation 30 jours et purge planifiee
- PostGIS obligatoire avec colonne geographique et index

## Criteres d'acceptation
- [ ] Chaque dette a un test qui echouait AVANT le correctif
- [ ] e2e complet vert apres corrections
- [ ] Rate limiting sur Redis (plus memoire)
- [ ] Recalcul des rappels a la publication (test)
- [ ] Compte provisoire fusionne correctement (test)
- [ ] PostGIS avec colonne geo et index (migration reversible)
